# mew-version-control
A version control system (just like git) but for Scratch!

The navigation is just like all my other projects, with a simple numbered menu.

The workflow for this program is pretty simple, and includes all you might need from a simple version control system. 
Firstly, you'll need to sign in and view the list of all your published projects (Support for private projects is in progress)
Then, you'd use the ID of one of the projects to create a local repository, where all the project data will be stored.
This repo can then be accessed through the menu, where you can see changes since last local commit.
If you have older versions of a project, you can also roll back and push remotely through the repo menu.
